1. 극한 (Limits)

함수 $f(x)$가 $x \to a$일 때 다가가는 값을 $\lim_{x\to a} f(x)$로 표기합니다.

핵심 기법

  • 직접 대입: 연속함수면 $\lim_{x\to a} f(x) = f(a)$
  • 인수분해: $\frac{0}{0}$ 꼴이면 분자·분모를 인수분해해 약분
  • 유리화: 근호가 있는 $\frac{0}{0}$ 꼴에 유용
  • 로피탈의 정리: $\frac{0}{0}$ 또는 $\frac{\infty}{\infty}$일 때 $\lim \frac{f}{g} = \lim \frac{f'}{g'}$

예제

$\displaystyle \lim_{x\to 2} \frac{x^2-4}{x-2} = \lim_{x\to 2} \frac{(x-2)(x+2)}{x-2} = \lim_{x\to 2}(x+2) = 4$

꼭 외워야 할 극한

  • $\displaystyle \lim_{x\to 0}\frac{\sin x}{x} = 1$
  • $\displaystyle \lim_{x\to 0}\frac{1-\cos x}{x} = 0$
  • $\displaystyle \lim_{x\to 0}\frac{1-\cos x}{x^2} = \frac{1}{2}$
  • $\displaystyle \lim_{x\to \infty}\left(1+\frac{1}{x}\right)^x = e$

2. 미분 (Derivatives)

도함수의 정의: $\displaystyle f'(x) = \lim_{h\to 0}\frac{f(x+h)-f(x)}{h}$

기본 공식

함수도함수
$x^n$$nx^{n-1}$
$\sin x$$\cos x$
$\cos x$$-\sin x$
$\tan x$$\sec^2 x$
$e^x$$e^x$
$\ln x$$\dfrac{1}{x}$
$a^x$$a^x \ln a$
$\arcsin x$$\dfrac{1}{\sqrt{1-x^2}}$
$\arctan x$$\dfrac{1}{1+x^2}$

미분법 규칙

  • 곱의 법칙: $(fg)' = f'g + fg'$
  • 몫의 법칙: $\left(\dfrac{f}{g}\right)' = \dfrac{f'g - fg'}{g^2}$
  • 연쇄법칙: $\dfrac{d}{dx}f(g(x)) = f'(g(x))\cdot g'(x)$
  • 음함수 미분: $y$를 $x$의 함수로 보고 양변 미분

예제 (연쇄법칙)

$y = \sin(3x^2)$의 도함수는 $y' = \cos(3x^2)\cdot 6x = 6x\cos(3x^2)$

3. 미분의 응용

접선과 법선

점 $(a, f(a))$에서 접선: $y - f(a) = f'(a)(x-a)$

극값 판정

  • 1차 도함수 판정: $f'(x)$의 부호 변화
  • 2차 도함수 판정: $f'(c)=0$이고 $f''(c)>0$이면 극소, $f''(c)<0$이면 극대
  • 변곡점: $f''(x)$의 부호 변화

관련 변화율 (Related Rates)

두 변수가 시간에 대해 변할 때 양변을 $t$로 미분합니다.

평균값 정리 (MVT)

$f$가 $[a,b]$에서 연속·$(a,b)$에서 미분가능이면, $\exists c \in (a,b)$, $f'(c) = \dfrac{f(b)-f(a)}{b-a}$

4. 적분 (Integrals)

부정적분: $\int f(x)\,dx = F(x) + C$, 여기서 $F'(x) = f(x)$

미적분학의 기본정리 (FTC)

  • Part 1: $\dfrac{d}{dx}\int_a^x f(t)\,dt = f(x)$
  • Part 2: $\int_a^b f(x)\,dx = F(b) - F(a)$

기본 적분 공식

$\int x^n\,dx$$\dfrac{x^{n+1}}{n+1} + C \;(n\neq -1)$
$\int \dfrac{1}{x}\,dx$$\ln|x| + C$
$\int e^x\,dx$$e^x + C$
$\int \sin x\,dx$$-\cos x + C$
$\int \cos x\,dx$$\sin x + C$
$\int \sec^2 x\,dx$$\tan x + C$
$\int \dfrac{dx}{1+x^2}$$\arctan x + C$

적분 기법

  • 치환적분 (u-substitution): $u=g(x)$, $du=g'(x)\,dx$
  • 부분적분 (BC): $\int u\,dv = uv - \int v\,du$
  • 부분분수 (BC): 유리함수를 간단한 분수의 합으로 분해

적분의 응용

  • 면적: $\int_a^b [f(x)-g(x)]\,dx$
  • 회전체 부피 (원판): $V = \pi \int_a^b [f(x)]^2\,dx$
  • 회전체 부피 (원통): $V = 2\pi \int_a^b x\,f(x)\,dx$
  • 평균값: $\bar{f} = \dfrac{1}{b-a}\int_a^b f(x)\,dx$
  • 호의 길이 (BC): $L = \int_a^b \sqrt{1 + [f'(x)]^2}\,dx$

5. 급수 (BC 전용)

수렴 판정법

  • n-th Term Test: $\lim a_n \neq 0$이면 발산
  • 기하급수: $\sum ar^n$은 $|r|<1$에서 $\dfrac{a}{1-r}$로 수렴
  • p-급수: $\sum \dfrac{1}{n^p}$는 $p>1$에서 수렴
  • 비율 판정법: $L=\lim|a_{n+1}/a_n|$, $L<1$ 수렴, $L>1$ 발산
  • 교대급수: 감소 & $\lim a_n = 0$이면 수렴

Taylor · Maclaurin 급수

$f(x) = \sum_{n=0}^\infty \dfrac{f^{(n)}(a)}{n!}(x-a)^n$

자주 쓰는 Maclaurin 급수:

  • $e^x = \sum \dfrac{x^n}{n!} = 1 + x + \dfrac{x^2}{2!} + \cdots$
  • $\sin x = x - \dfrac{x^3}{3!} + \dfrac{x^5}{5!} - \cdots$
  • $\cos x = 1 - \dfrac{x^2}{2!} + \dfrac{x^4}{4!} - \cdots$
  • $\dfrac{1}{1-x} = 1 + x + x^2 + \cdots \;(|x|<1)$
  • $\ln(1+x) = x - \dfrac{x^2}{2} + \dfrac{x^3}{3} - \cdots \;(-1
