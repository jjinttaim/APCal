이 16일 동안 가장 우선해야 할 5가지

  1. Taylor / Maclaurin 급수 — 매년 FRQ에 1문제 고정. 자주 쓰는 5개($e^x, \sin x, \cos x, \frac{1}{1-x}, \ln(1+x)$)는 반드시 암기.
  2. 수렴 판정법 — n-th term, 비율, p-급수, 적분, 비교, 교대급수, 절대수렴. 어느 상황에 어느 판정법인지 흐름도로 정리.
  3. 적분 기법 — u-치환은 필수, 부분적분(BC), 부분분수(BC), 삼각치환(가끔), 그리고 improper integrals.

BC 전용 공식

  • 매개변수 도함수: $\dfrac{dy}{dx}=\dfrac{dy/dt}{dx/dt}$, $\dfrac{d^2y}{dx^2}=\dfrac{d(dy/dx)/dt}{dx/dt}$
  • 매개변수 호의 길이: $L=\int_a^b \sqrt{(x'(t))^2+(y'(t))^2}\,dt$
  • 극좌표 면적: $A=\dfrac{1}{2}\int_\alpha^\beta r^2\,d\theta$
  • 극→직교: $x=r\cos\theta,\ y=r\sin\theta$, $\tan\theta=y/x$
  • Euler's method: $y_{n+1}=y_n + h\cdot f(x_n,y_n)$
  • Logistic: $\dfrac{dP}{dt}=kP\!\left(1-\dfrac{P}{L}\right)$, 변곡점은 $P=L/2$
  • 비율 판정법: $L=\lim\left|\dfrac{a_{n+1}}{a_n}\right|$, $L<1$ 수렴, $L>1$ 발산, $L=1$ 미정
  • Taylor 오차(라그랑주): $|R_n(x)|\le \dfrac{M}{(n+1)!}|x-a|^{n+1}$

꼭 외워야 할 Maclaurin 급수

  • $e^x = \sum_{n=0}^\infty \dfrac{x^n}{n!}$ (모든 $x$)
  • $\sin x = \sum_{n=0}^\infty \dfrac{(-1)^n x^{2n+1}}{(2n+1)!}$ (모든 $x$)
  • $\cos x = \sum_{n=0}^\infty \dfrac{(-1)^n x^{2n}}{(2n)!}$ (모든 $x$)
  • $\dfrac{1}{1-x} = \sum_{n=0}^\infty x^n$ ($|x|<1$)
  • $\ln(1+x) = \sum_{n=1}^\infty \dfrac{(-1)^{n+1} x^n}{n}$ ($-1
  • $\arctan x = \sum_{n=0}^\infty \dfrac{(-1)^n x^{2n+1}}{2n+1}$ ($|x|\le 1$)

FRQ 빈출 6가지 — 이건 무조건 풀어보고 가자

BC FRQ는 매년 거의 같은 6개 유형이 반복됩니다. 각 유형을 최소 2년치 풀어보세요 (College Board 공개 문제 무료).

  1. 변화율 (Rate-in / Rate-out): 두 함수가 들어오고 나가는 비율 → 누적량은 적분, 변화율은 차이. "increasing fastest" → $f'=0$ where derivative changes sign.
  2. 그래프 해석: $f'$의 그래프가 주어지고 $f$의 극값, 변곡점, 절대극값을 묻는다. FTC로 $f(b)=f(a)+\int_a^b f'$.
  3. 입자 운동 / 매개변수 (BC): 속도 벡터 $(x'(t), y'(t))$, 속력 $\sqrt{x'^2+y'^2}$, 이동 거리 = 속력의 적분.
  4. 면적·부피: 두 곡선 사이 면적, 회전체(원판/원통), cross-section(정사각형/반원/정삼각형).
  5. 미분방정식: slope field 그리기 → 변수분리로 해 구하기 → 초기조건 적용. BC는 logistic 또는 Euler's method가 자주 나옴.
  6. Taylor 급수 (BC): 처음 4개 항 적기 → 일반항 → 수렴 반경/구간 → 라그랑주 오차 한계.
⏱ 시간 페이스: FRQ 6문제 / 90분 = 문제당 15분. Part A (계산기 가능, 2문제) 30분, Part B (계산기 ×, 4문제) 60분. 풀이 과정을 반드시 적기 — 답만 적으면 부분점수 못 받습니다.
